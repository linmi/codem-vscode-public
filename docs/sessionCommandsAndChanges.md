# 会话命令与轮次文件变更

## 目标和交互边界

- `/` 是本地会话操作入口，替换顶栏会话工具。首次输入 `/` 展示分组命令，支持搜索、键盘选择和取消；取消保留草稿，选中后进入对应操作流程。运行中开放补充指令，空闲时开放旁路提问和修改会话的操作。不可用项说明原因，不把本地命令发送给模型。
- 清空、删除、Shell 执行继续经过明确确认；取消不产生 Host 操作。技能、能力目录和工作目录复用对应详情面板，不在打开菜单时读取目录或执行 RPC。输入草稿由 Webview state 保存，操作回执保留失败草稿且不覆盖后续编辑。切换会话清理菜单及待确认状态，重载恢复匹配当前会话的草稿。
- 文件变更由 Host 使用 Core turnId 归属，展示在该轮最后一条消息之后、下一轮之前，不进入工具折叠区。进行中的新消息更新末尾位置，停止或失败保留已发生的修改；无修改不显示空卡片。同一文件多次修改按差异片段展示，不伪造净增删统计。
- 文件资源面板保留当前已加载会话记录的全部差异。UI 只收到不透明句柄和脱敏标签；正文仍由 Host 打开。历史恢复和翻页从 schema 13 的 file-diff 记录重建句柄，重载替换旧句柄，新会话清理旧资源；失败时保留当前已验证内容。
- 新增 UI 状态仅用于菜单、焦点和展示，不建立协议或目录缓存。命令选择本身零 RPC；实际操作复用已有 Host 流程。差异展示和恢复不新增网络请求，沿用已有历史页读取。

## 验证

实现后填写单元/集成、模拟界面、真实 Core 和 VS Code 的验证范围。
