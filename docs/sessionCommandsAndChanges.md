# 会话命令与轮次文件变更

## 目标和交互边界

- `/` 是本地会话操作入口，替换顶栏会话工具。首次输入 `/` 展示分组命令，支持搜索、键盘选择和取消；取消保留草稿，选中后进入对应操作流程。运行中开放补充指令，空闲时开放旁路提问和修改会话的操作。不可用项说明原因，不把本地命令发送给模型。
- 清空、删除、Shell 执行继续经过明确确认；取消不产生 Host 操作。技能、能力目录和工作目录复用对应详情面板，不在打开菜单时读取目录或执行 RPC。输入草稿由 Webview state 保存，操作回执保留失败草稿且不覆盖后续编辑。切换会话清理菜单及待确认状态，重载恢复匹配当前会话的草稿。
- 文件变更由 Host 使用 Core turnId 归属，展示在该轮最后一条消息之后、下一轮之前，不进入工具折叠区。进行中的新消息更新末尾位置，停止或失败保留已发生的修改；无修改不显示空卡片。同一文件多次修改按差异片段展示，不伪造净增删统计。
- 文件资源面板保留当前已加载会话记录的全部差异。UI 只收到不透明句柄和脱敏标签；正文仍由 Host 打开。历史恢复和翻页从 schema 13 的 file-diff 记录重建句柄，重载替换旧句柄，新会话清理旧资源；失败时保留当前已验证内容。
- 新增 UI 状态仅用于菜单、焦点和展示，不建立协议或目录缓存。命令选择本身零 RPC；实际操作复用已有 Host 流程。差异展示和恢复不新增网络请求，沿用已有历史页读取。

## 验证

各 Cycle 分开记录自动检查、模拟界面和真实运行验证。

文件变更 Cycle：`pnpm check`（含新增轮次定位、重复事件、历史恢复/失效句柄/失败保留回归）与 `pnpm build:vscode` 通过。现有内置浏览器验证三轮样例：两轮各有独立摘要、同文件两段修改、停止保留、第三轮无空摘要、不可用按钮禁用、点击通过不透明句柄进入现有打开流程；工具折叠区内摘要数量为 0，浏览器日志无错误。独立 `turnChangesChecks.mjs` 已加入但未通过 CLI 执行。真实 Core、真实 VS Code 本 Cycle 未执行。

会话命令 Cycle：

- 已迁移 18 个命令，删除旧顶栏入口、四页签大面板及手写 slash 列表。新增 shadcn/ui Command（cmdk 1.1.1），复用已有 Dialog、Select 和 Button。能力目录打开本身零 RPC，刷新和执行沿用既有 Host 校验。
- 旁路提问、补充指令和 Shell 共用主输入框；普通消息草稿独立保存。最近一个能力输入草稿仅在会话与模式均匹配时恢复，模式切换不会把 Shell 文本带入旁路提问。附件保留给普通消息。失败保留当前输入，迟到回执不清除后续编辑；切换会话返回普通输入并清理弹层。
- Shell、清空、删除保留确认；确认按钮阻止重复提交。回退仍使用检查点和范围两步选择。短窗口空间不足时，命令菜单覆盖输入区域，确保搜索框和可滚动列表位于可见区域。
- 自动检查：`pnpm check` 通过（279 项单元/集成 fixture 测试，包含命令可用性、运行状态、无会话限制与失效回执）；`pnpm build:vscode` 通过；浏览器检查脚本语法通过。
- 模拟界面：复用唯一内置浏览器标签页，验证深浅主题、380px 窄栏及 480px 矮窗口、展开目录选择器、键盘选择/取消、Shell 取消与普通草稿恢复、不同能力模式输入隔离、失败保留、运行中补充指令和停止后禁用、删除取消、回退两步与取消、旁路取消、切换会话复位。浏览器控制台无 error/warn。
- `sessionCommandsChecks.mjs` 已更新回归断言，但本 Cycle 未通过 CLI 执行；以上模拟界面结果来自内置浏览器操作。真实 Core、真实 VS Code 未执行，不把模拟回执视为端到端成功。未新开 Chrome 或 VS Code 窗口。

## 紧凑布局 Cycle

确认操作使用约 420px 的内容自适应弹窗，Shell 命令保留较宽的阅读区域，目录仍使用可滚动的详情面板。文件资源和轮次摘要采用横向列表，空间不足时按容器宽度换行；长路径完整换行，操作按钮不被挤出。此 Cycle 只调整展示：首次打开、重复打开、取消、失败提示、重载及会话切换继续使用既有状态和清理流程，不新增状态、请求或持久化数据，不改变操作目标和确认语义。验证覆盖深浅主题、窄栏、长路径、不可用预览、实际展开选择器以及取消后再次打开。
