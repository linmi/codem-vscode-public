# Next Edit

## 实施边界

当前只有光标处行内补全和选区修改审阅，没有下一处修改预测。目标为当前文件的一处预测，复用 Core 文本旁问，不引入专用服务、Proposed API 或第二个模型连接。VS Code 基线 ^1.105.1、类型 1.105.0；使用该版稳定的 CodeLens、Decoration、TextEditor.edit（独立 undo stops），依据：https://github.com/microsoft/vscode/blob/1.105.1/src/vscode-dts/vscode.d.ts。

状态所有者为 `integrations/nextEdit/nextEdit.ts`，提示与严格锚点解析在同目录 `nextEditProposal.ts`。只在内存保存当前编辑器的有界文本、最近一次编辑、生成租约和一处未接受建议。不保存代码到扩展存储，不跨文件预测，不重用旧模型结果。

首次使用通过命令/状态栏手动预测，复用已连接且空闲的 Core；不默认自动请求，避免与行内补全竞争。最近编辑、当前光标及诊断用于预测；没有可靠下一处时允许空结果。重复触发取消旧请求并等待清理，仅最后一次有效请求可继续。等待期间可取消；文档修改、切换编辑器、关闭文档、工作区变化和销毁使结果失效。会话切换由既有生成通道取消；未接受建议再用连接/模型身份校验并清除。重载从空状态开始。

建议通过原生装饰/悬浮内容、CodeLens 和状态栏展示。Tab 第一次跳到目标，第二次接受；仅有有效建议且不与建议列表、灰字、snippet 或 Tab 焦点模式冲突时接管 Tab。Esc 清除建议或取消生成。接受前再次校验信任、工作区、原文、文档版本和会话身份；接受只改当前编辑器的一块文本，不主动保存，可一次撤销。失败不自动重试、不应用过期结果。

每次生成：一次工作区路径校验 → generateText 内一次认证 → 必要时一次 thread/start → 一次 side question；零 Agent turn、不调用工具。15 秒生成预算，取消后沿用 Core 终态/回收逻辑。跳转和拒绝无 RPC；接受仅校验工作区并执行一次编辑器事务。记录耗时和生成调用次数，不记录源代码。
