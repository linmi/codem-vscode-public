# 编辑器选区上下文

在代码编辑器中选择文本后，输入框显示 `文件名 10–15 ×`。单行选区只显示一个行号；结束位置位于下一行第 0 列时，该行不计入范围。长文件名省略，悬停可查看相对路径和范围。点击标签定位源选区，点击关闭按钮取消附带。当前使用 VS Code 的主选区。

## 边界与生命周期

- `integrations/editorSelection.ts` 监听本地编辑器事件并负责定位；`resources/selectedCode.ts` 独占选区内容、版本和引用 ID；Webview 只接收显示元数据，不接收文件 URI 或代码正文。
- 首次显示从当前编辑器捕获选区，重复焦点事件不会重复生成引用。切到聊天、隐藏/恢复界面、移动到编辑器标签页及 Webview 重载都保留 Host 中的选区。扩展重启重新读取编辑器，不持久化代码副本。
- 删除或成功发送后，同一未变化选区不会因焦点返回而再次附带。新选区替换旧选区；取消选择、切换到无选区文件、修改/关闭源文档、切换已有会话/空间/工作区时清除引用。首次连接与首次创建线程保留待发送选区。
- 普通聊天发送附带显示中的选区 ID，由 Host 校验 ID、工作区和信任后把捕获的代码追加到提交文本。失败保留草稿与仍有效的引用；过期 ID 明确失败，不能代换成较新的选区。成功回执只消费对应 ID。旁路提问、指令输入等其他模式不附带该选区。
- 显式「加入上下文/解释/修复/改进」成功把代码加入草稿后，清除原自动引用，避免重复附带；失败不清除。
- 24000 字符以上的代码选区显示错误并禁止发送；合并文本超过 32000 字符时拒绝发送并保留草稿。空白选区不附带。未信任工作区不捕获代码。
- 选区变化与标签显示的 RPC/子进程次数均为 0。发送沿用现有 `chat.send` 生命周期，不增加初始化或模型调用；定位只使用 VS Code 文档 API。

## 已发送代码的展示

发送成功后的用户气泡由 `transcript/userMessage.tsx` 渲染：正文在上，代码显示为文件名与行号卡片，默认折叠，展开后显示保留缩进的语法高亮代码，可单独复制。复制失败显示重试提示。展开与复制状态只属于当前消息视图，重复快照保留，重载或切换会话后清理；折叠不更改消息内容。长文件名省略、完整路径悬停可见，代码区域独立滚动。

`shared/editorContext.ts` 统一生成和识别既有代码上下文格式，实时消息与历史回放共用展示；发送内容与 Core 历史格式不变。只识别完整已知格式，普通文本、HTML 和无效范围保持字面展示；保留解释、修复、改进指令与诊断。组件不请求 Host 或 Core。

## 验证入口

`editorContext.test.ts` 覆盖生成/解析、重复选区、代码空白、诊断与无效格式。「已发送选区代码」模拟场景用于检查折叠、键盘操作、复制、深浅主题及窄栏。

`selectedCode.test.ts` 验证快照、过期 ID、移除、消费竞态、上下文切换和长度限制；`editorSelection.test.ts` 使用 VS Code fixture 验证选区事件、行号、失焦、定位和发送回执。模拟预览包含「代码选区」「代码选区 · 发送失败」，用于检查标签、移除、定位反馈、发送清理及失败保留。
