# 编辑器修改审阅

## 本轮目标与行为（实施前）

现有修复/改进入口只把选区送入聊天；Core 的聊天补丁对应已经执行的修改，不能冒充待应用建议。本轮将这两个编辑器入口改为一次旁问生成建议，解释和加入上下文仍进入聊天草稿。生成不执行 Agent 工具，不写原文件。修改范围限制为用户所选文本，模型返回有原文锚点的替换块；锚点不唯一、重叠、越界或格式错误明确失败。

首次使用捕获当前文档（包括未保存内容）、版本和选区；生成进度可取消，重复操作不并发请求。成功后在原文件注册 CodeLens 和范围装饰，按块预览、接受或拒绝，也支持全部接受/拒绝与命令面板审阅。预览使用原生双栏 Diff，右侧为只读建议。接受通过 WorkspaceEdit 写入编辑器缓冲区，支持原生撤销，不自动保存；拒绝不修改原文件。

审阅状态只属于本窗口本次扩展生命周期，最多一个文件。已接受块保留在文档，剩余块继续审阅；新的生成必须先处理现有建议。文档发生外部编辑（包括撤销）、关闭、工作区切换、连接/账户/会话切换或扩展重载会使剩余建议失效，不回滚已经接受的内容。不持久化原文或建议。生成失败/取消不会覆盖文档，失败可重新发起；应用失败保留尚可核实的建议，无法核实则失效并提示重新生成。

耗时与次数：每次生成复用当前连接，沿用旁问的认证与可选首次 thread/start，再发一次 sideQuestion/start；不新建每块模型请求。预览、接受、拒绝、再次打开审阅均为本地操作。记录生成耗时，不记录源码。

## 验收计划

纯状态回归覆盖唯一锚点、重复文本、重叠、增删改、CRLF、未保存内容、逐块混合决定、全部决定及失效。宿主适配验证 WorkspaceEdit 回填、取消、文档版本/会话变化、重复点击与资源清理。复用现有开发宿主，实际操作修复生成、多块预览/接受/拒绝/撤销，并验证行内补全接受/取消、终端右键选区/最近输出、SCM 生成回填。测试文件/仓库独立于用户暂存内容；不执行真实提交或改变用户原有文件。各层结果在完成后分别记录。

## 实现与验证记录（2026-09-21）

- 修复与改进只生成待审阅建议。生成状态、原文锚点与接受决定由独立 `EditorReview` / `EditProposal` 持有，通过窄接口调用现有连接；没有复制连接或会话状态机。
- 原文件 CodeLens 提供预览、接受、拒绝；原生 Diff 标题栏提供处理光标所在修改块的按钮。不在任何块中或同一行存在多个候选时，显式选择修改块。全部接受/拒绝可从命令面板使用。
- 同一会话暂时忙碌时保留建议，空闲后继续；内容、版本或连接/线程身份变化才失效。应用前后核实精确文本，拒绝过期结果。生成取消、重复请求、文档编辑、会话切换、应用失败、全部/逐块决定、延迟到达的自身编辑事件均有宿主适配回归。
- 新建聊天草稿的 `codePrompt` 不再接受修复/改进，类型和运行时均拒绝。历史会话已经持久保存这两类文本包裹，`codePromptParts` 只保留读取渲染；不再产生旧输入。删除该读取能力的前提是历史格式完成迁移或停止支持；当前通过历史样例渲染测试维持可读性。
- 单元/集成：编辑建议、Host 适配与历史格式负向回归通过；全量 lint、类型检查、默认测试及构建通过。
- 真实 Core：`pnpm --filter codem test:live --editor-review` 通过。一次旁问、零 Agent 轮次，约 4785ms，生成两块独立修改，混合接受/拒绝后保留未接受原文。
- 真实 VS Code：复用现有开发宿主，以临时函数样例生成两个修改块；先原生 Diff 预览，再接受加法修复、拒绝乘法修复，核实只有已接受块进入原文件。原文件 CodeLens 与 Diff 工具栏两条路径均通过；原文件原生撤销通过。临时文件自动保存由用户已有编辑器设置触发，扩展本身不调用保存。
- 模拟 Webview：未新增或修改 Webview 组件，未另开模拟浏览器；原生 CodeLens/Diff 的验收不以网页模拟代替。

本轮不把 Core 聊天中已经执行的文件修改重新包装成“待接受建议”；这些已有变更仍按原来的只读差异入口查看。
