## Cycle 1：安装包必须包含自身运行时

### 问题与目标边界

- 原 ZIP 只有三个 JAR，共约 2.4 MiB，没有 Core 或认证程序。插件靠向上搜索项目 `node_modules` 运行，离开开发仓库就无法连接。
- 构建复用 `@codem/app-server/build`，沿用现有 schema 2 `bin/app-server/runtime.json`，不再产生第二套打包格式。它是 JetBrains 的开发依赖，不进入生产 JVM。
- Gradle 2.5.0 的 PrepareSandboxTask 将原生文件放到插件目录，buildPlugin 收进 ZIP；JAR 只包含 Kotlin 与 UI。已核对本地缓存的 2.5.0 源码和最终 ZIP。当前官方文档含更新版本的 nativeVariants，不移植到锁定的 2.5.0：[官方任务说明](https://plugins.jetbrains.com/docs/intellij/tools-intellij-platform-gradle-plugin-tasks.html#prepareSandbox)。
- RuntimeLocator 只解析安装目录，平台、schema、版本、包名、文件名、许可证、执行权限和二进制 SHA-256 不匹配即失败。删除项目搜索和旧多平台 BundleManifest/BundleTarget；该旧格式未进入之前 ZIP，也无独立消费者或持久用户数据。

### 所有权、交互和调用次数

- 构建任务拥有 `apps/jetbrains/build/runtime`；每次打包重新校验并准备两个锁定二进制，不新增全局缓存或后台服务。缺文件/版本错立即失败，不生成伪成功安装包。
- 安装目录拥有不可变运行文件。每次运行时解析读取一份清单，对两个二进制各计算一次哈希；该层不认证、不启动 Core。连接、取消、失败和关闭仍由原有 ProjectSession/CoreProcess 管理。
- 不改聊天/草稿保存范围，不引入反向依赖或共享可变状态。重新安装替换插件文件；无需迁移用户历史。
- nativeRuntime 测试独立解压 ZIP 到含空格/中文的临时目录，使用空 HOME、PATH 和明确环境；执行一次认证 `--version`、一次 Core initialize/initialized，随后关闭并确认进程消失。临时文件由测试清理。

### 验证

- `pnpm check`：本轮完整通过，包括 lint、全工作区类型检查、fixture 测试和 JetBrains 75 项领域测试。此前 App Server 空间测试超时在本轮未复现，未修改或放宽这些测试。
- `pnpm --filter @codem/jetbrains test:runtime`：通过，含完整 IDEA 适配层编译与 ZIP 构建。使用真实锁定二进制，无账户登录/模型调用。
- 空 PATH 原生握手及关闭：本机一次样本 106ms（不含构建和 ZIP 解压，不作为性能承诺）。Core 报告 0.8.45+2732.g1f24a50.dirty；发布版本校验按已存在的 SemVer build metadata 规则保持 0.8.45。
- 产物：`apps/jetbrains/host/build/distributions/host-0.1.0.zip`，37,560,559 bytes（35.82 MiB），仅 darwin-arm64。ZIP 条目确认 Core、认证程序 Unix 权限为 0755，包含两份运行时许可证及项目 LICENSE。

## Cycle 2：账户刷新必须允许重复操作并拒绝迟到结果

- 用户可见问题：第一次 auth status 成功后，后续“刷新账户”被永久忽略。根因是 Host 在成功分支推进 accountGeneration，finally 却只在旧代次仍相等时释放 accountRefresh；两个独立变量产生了永不释放的状态。
- 目标边界：AccountStatusRefresh 单独拥有当前读取尝试和关闭状态，把“发布结果”和“释放本次读取”放在同一个同步操作内。I/O、CLI 和调度仍在宿主后台线程，不在该锁内执行。
- 首次显示 checking；已登录的显式刷新保留资料并显示 refreshing。重复点击合并到同一次读取；每个新尝试执行一次 auth status，不缓存认证结果。成功、失败、超时都释放尝试并允许重试。
- 正常返回与看门狗竞争同一尝试，只有一个能发布终态。旧超时/失败不能释放或覆盖新的读取。开始登录、退出时撤销旧读取；Host 销毁永久关闭该读取所有者，晚到结果不得回写。CLI 子进程仍由已有 8 秒硬超时负责有界结束，没有把 I/O 移到 EDT。
- 移除 Host 中 accountGeneration、账户刷新布尔值及只认 checking 的旧超时判断；超时依据真实读取身份，而不是页面是否仍显示 checking。定位运行时失败也经同一尝试发布，不再绕过身份判断。
- 新增四项回归：成功后再次读取、失败/超时后重试、登录/退出/关闭失效、并发完成与超时仅一个终态。JetBrains check（共 79 项）、lint、包含真实适配层的 buildPlugin 和独立打包原生测试通过。
- 第二次打包原生样本：握手+关闭 424ms，ZIP 37,563,420 bytes；不把单次时间差当成性能回归或提升。
- 没有改变认证凭据或全局退出语义，没有新增存储、缓存或生产依赖。此次仅完成账户刷新这一边界，不把浏览器登录取消、真实空间切换或完整 A01/A02 验收标为完成。
- 真实 IDEA/模型/VS Code 仍未执行；原有 IDEA 窗口停在安装的第三方声明确认，没有接受、重载或重复安装。
