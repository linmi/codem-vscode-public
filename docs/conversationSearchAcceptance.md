# 当前会话正文搜索

## 边界与交互

原实现只过滤已加载会话标题。本 Cycle 搜索当前会话全部已保存的用户消息和助手回复，不搜索隐藏提示、工具原始参数、思考或附件正文。不调用模型，不建立第二份持久历史。

`@codem/history` 复用 schema 13 流式重放、工作区绑定、序列、文件身份和符号链接校验。单次搜索一次完整重放，最多保留 200 个消息匹配并明确提示截断。命中游标绑定文件版本，点击后一次重放读取目标附近最多 30 轮；旧游标不会跳到新内容。文件变化/损坏明确失败，不返回部分搜索结果。

VS Code `ConversationSearch` 独立拥有请求取消、随机命中 ID 与 Host 游标映射；状态只活到当前连接/会话。首次打开无结果或重试入口；显式提交搜索，重复提交取消旧读取。关闭取消搜索，切换/新建/发送/退出清理搜索请求及命中。UI 使用 shadcn Dialog/Input/Button，结果摘要标记关键词，跳转后突出原消息；可返回最新消息。历史位置发送前先恢复最新记录，失败保留草稿。Core threadId、现有历史消息/附件/审批规则保持不变。UI 不接触文件路径或游标。

每次搜索一次认证校验和一次本地重放，零模型/历史 RPC；点击命中一次认证校验和一次重放，不逐页重复扫描。UI 查询和搜索命中不会持久化。Node 历史读取 → VS Code Host → protocol 显示契约 → 共享 UI，无反向依赖。JetBrains 未接入时该能力为 null，不展示入口。
