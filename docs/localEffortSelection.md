# 本地思考强度选择

四档强度来自 `@codem/protocol`，默认 medium。菜单由 Webview 的 shadcn/ui Select 持有，无需模型目录、认证或 Core 连接。信号图标分别点亮 1 / 2 / 3 / 4 格，选中项和图标均使用 Host 快照中的同一值。

## 操作与状态所有权

- 首次使用：Webview 在首个 Host 快照前即可展示默认菜单；Host 随后发布本地保存值。打开和关闭菜单零 RPC、零子进程。
- 未连接时选择：Host 校验白名单值，更新内存偏好并写入 workspaceState。写入期间阻止重复选择和连接，完成后保持未连接；无认证、目录读取或 Core 初始化。
- 连接与首次发送：待应用强度覆盖本次目标空间的已保存强度，成功写入该工作区/空间偏好后清除待应用值。首次 thread/start 使用该强度。其他已保存字段保持不变，包括暂不可用的模型偏好。
- 已连接时选择：复用设置事务；现有线程先读模式、必要时 unsubscribe/resume、再读模式确认。菜单和图标在应用成功后更新；失败保留原值并显示错误。仅打开菜单不执行这条调用链。
- 重复选择当前值：无设置变更；运行、连接或配置过程中禁用选择。切换上下文或进入忙碌状态关闭菜单。
- 取消：Escape / 点击外部关闭，仅改变 Webview 弹层状态，不保存、不通信；焦点回到触发器。
- 重载：未连接的待应用值由 workspaceState 恢复；成功归属空间后按已有空间偏好流程恢复，不建立第二份永久设置。
- 切换空间：已消费的待应用值不传播到其他空间；读取目标空间自己的设置。
- 保存失败：明确提示尚未保存，内存值仍可用于当前连接；待应用值只在空间设置写入和清理都成功后从内存移除，下次连接可重试。

## 准出标准

覆盖离线选择零连接、重载恢复、首次发送参数、空间归属与清理、非法消息拒绝、忙碌状态和应用/存储失败。模拟界面实际展开四档菜单，检查深浅主题、键盘取消与焦点、四档信号、窄窗口边界。真实 Core 和 VS Code 验证需独立报告，不能由模拟结果替代。
