## 查看入口

复用现有 `http://127.0.0.1:4318/` 预览服务。没有服务时先运行 `pnpm build:vscode`，再运行 `pnpm --filter codem exec node --experimental-strip-types tests/webviewPreview.ts`；不要重复启动服务或浏览器实例。4318 已被其他并行任务占用时，用 `CODEM_WEBVIEW_PREVIEW_PORT=<端口>` 在空闲端口启动本任务自己的服务，结束后只停止该服务；端口被占用时服务报错退出，不会改用其他端口。

推荐直接打开：

- `/?scenario=toolDetails`：六类工具的参数、来源、命令与多行输出，默认展开，正文仍在工具折叠区之外。
- `/?scenario=artifactGallery`：文件、图片、图表、URL、diff 五类卡片与长标题；不可用版本见 `artifactUnavailable`。
- `/?scenario=imageGallery`：960×540 的本地 PNG、文件和目录附件；图片可放大并恢复焦点。`imageUnavailable` 首次加载失败，重试后成功。
- `/?scenario=resourceBackground`：运行/退出终端及六种唤醒任务状态。`resourceFiles` 展示完整、部分、二进制、无预览差异；`resourceTools` 展示 MCP 与工具列表。
- `/?scenario=catalogEnvironment`：运行环境与依赖；同组提供技能、配置、Hooks、插件、权限、空间、模型能力、实时快照共九类目录，以及加载中、空结果、过期失败。
- `/?scenario=runtimeDetails`：展开 Token 用量、修改汇总、输出保护及 Hooks；执行计划从聊天区右下角的任务按钮打开。
- `/?scenario=richMarkdown`：标题、引用、任务列表、表格、链接、TypeScript 和 diff 代码块。

所有链接均可加 `&theme=dark`。左侧目录使用既有 shadcn Button / Collapsible；窄窗口从顶部目录按钮选择场景。

## 状态与操作约定

- 首次进入：URL 决定场景和主题。需要检查的资源面板、工具详情、运行详情及会话命令自动进入对应流程；能力目录自动选中对应分类。
- 重复与重置：重置重新创建独立快照、面板标识和会话身份，清除输入、图片尝试次数、已记录动作及旧弹层；同一场景可重复检查。
- 取消与失败：沿用正式组件的关闭、Escape、取消及禁用语义。图片样例第一次失败、重试成功；发送仍固定返回拒绝，保留草稿，不伪造模型完成。旁路回答可取消，结果变为“已取消”。
- 重载与切换：重载恢复 URL 的初始样例；单独切换主题保留当前交互状态；切换场景或重置撤销旧动画帧、DOM 观察和刷新定时器，避免旧面板重新出现。页面退出时清理上述资源。
- 模拟动作：新建清空消息和附件；移除附件更新卡片；停止将运行记录标为中断并固定计时；问题提供上一题/下一题/提交，回退提供检查点/范围/取消。目录刷新恢复该类样例内容。以上只用于展示，不能替代真实 Host 的审批、问答草稿、持久化或停止协议验收。
- 外部动作：点击产物、diff、文件或后台日志仅显示模拟提示。会话管理、真实目录权限、真实终端等未实现完整后端模拟；不能把按钮动作已记录当成操作成功。

`previewContent.ts` 集中提供新增内容；`previewState.ts` 创建独立快照；`previewRuntime.ts` 持有本页交互和清理职责。页面挂载的是生产 `@codem/ui`，快照经 VS Code bridge 异步交给 React；预览先确认界面已提交当前样例（外壳 `data-phase`、运行详情按钮的 `data-thread-id` 与工作区标签），再操作真实控件，最多等待 3 秒，缺失时明确报错。所依赖的 `@codem/ui` 元素集中在 `previewHooks.ts`。会话命令场景由 Host 下发 `/命令` 草稿（与挂载时的草稿回放不冲突），草稿到达即展开命令菜单（与输入 `/` 相同，旁路提问运行中也会展开），再点选对应命令。不会新建一套预览组件或改变生产协议。

`fixtures/previewDashboard.png` 为本地生成的原创测试图，无外部素材依赖；只由模拟预览服务提供。
